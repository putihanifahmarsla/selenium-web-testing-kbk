# Automated Web Testing — Sistem Manajemen KBK

## Project Overview

Proyek ini merupakan bagian dari Project-Based Learning (PBL) yang berfokus pada pengujian aplikasi Sistem Manajemen KBK menggunakan Selenium WebDriver dan Java.

Pengujian dilakukan untuk memeriksa fungsi aplikasi dan mendokumentasikan hasil eksekusi pengujian.

## Objectives

- Memverifikasi fungsi login.
- Menguji fungsi pengelolaan data pengguna.
- Mendokumentasikan hasil pengujian melalui screenshot.
- Mengidentifikasi ketidaksesuaian antara hasil aktual dan hasil yang diharapkan.

## Tools & Technologies 

- Java
- Selenium WebDriver
- Microsoft Edge
- IDE For Java Developers - 2024-03

## Test Scope

Pengujian mencakup skenario login serta beberapa fungsi pengelolaan data pengguna, sesuai script dan pengujian yang tersedia di repository.

## Testing Process

1. Menyiapkan aplikasi dan lingkungan pengujian.
2. Menjalankan script Selenium WebDriver.
3. Memeriksa hasil aktual berdasarkan expected result.
4. Mendokumentasikan hasil pengujian melalui screenshot dan laporan.

## Test Results

Hasil pengujian dan status setiap test case akan didokumentasikan berdasarkan hasil eksekusi aktual.
